> **Neural Network Library in C**

Versions range from the original December 24 implementation to January 21. For the most up-to-date code, please see either of the January 21 versions (Momentum 2 or Preferences).

Earlier versions are included to show the development process. At the time, I wasn't using GitHub for version control, so I saved copies of the project in separate folders at different checkpoints.

**How to Run**

Open the Version Tue Jan 21 adding preferences folder in an IDE.

Run and build the PX5NET2 target.

The program will train the neural network and print the results for all four XOR inputs.

Note: Occasionally, training does not converge because of randomized initialization. If this happens, stop the program and run it again.
